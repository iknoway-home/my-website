# UX改善計画

| 項目 | 何が問題か | どう直すか | 優先度(高中低) | 今回実装したか |
|---|---|---|---|---|
| 初回表示の説明 | ローダーが `Loading...` だけで、誰の何のサイトか分からない | ページタイトルとローダーに iKnoWay、アニメ・ゲーム・制作物を明記する | 高 | はい |
| テーマ選択の保存 | テーマがタブを閉じると失われ、明示した `?theme=` も保存済みテーマに負ける | `localStorage` に保存し、明示指定を優先する | 高 | はい |
| テーマ切替の説明 | テーマごとにボタン名が違い、保存されることも伝わらない | 全テーマ共通で現在テーマと保存動作を `aria-label` / ツールチップに示す | 中 | はい |
| 更新日の表示 | 一部テーマだけ日付があり、現在の更新状況が分からない | 共通データの日付を全テーマのフッターに表示する | 中 | はい |
| ファーストビューの行き先 | 全画面ヒーローだけでは、スクロール後に何があるか分からない | デスクトップのヒーロー高を抑え、直後に自己紹介・ゲーム・アニメ・映画・制作・連絡への共通リンクを置く | 高 | はい |
| 浮遊ボタンの整理 | 前・次・先頭/末尾の円形ボタンが3個並び、矢印だけでは役割が伝わらない | 右下の1個に統合し、通常は次セクション、最終位置では先頭へ戻す | 高 | はい |
| テーマ変更の視認性 | テーマによって薄い文字色になり、主要操作が背景に埋もれる | 共通層で本文相当の文字色、同色ボーダー、薄い面を保証する | 高 | はい |
| AI的な演出の棚卸し | cyber / vaporwave / anime などは世界観としてネオン・グラデーション・装飾アニメを多用している | 各テーマの固有性を残す表現と、テンプレ的なglow・均質カードをテーマ単位で切り分ける | 高 | はい（cyber / vaporwave / anime） |
| プロジェクト導線 | 制作物は1件で、テーマによっては第一画面から遠い | 実績が増えた時点でヒーロー直下に代表作を1件だけ置くことを検討する | 高 | いいえ |
| 19テーマの網羅確認 | 全テーマの世界観が独立しており、共通変更の目視範囲が広い | 実ブラウザが使える環境でPC・375px・ライト/ダーク相当を一巡する | 高 | はい（確認用URLを列挙） |

## AI的な演出の棚卸し記録

- `cyber`: CRT・グリッチ・ヒーローのネオンは残し、作品カードのglowと斜線、電力オーラ、汎用プロフィール絵・架空ゲージを外して端末レコード型の一覧にした。
- `vaporwave`: 遠近グリッド・クローム文字・ピンク/シアンのグラデーションは残し、作品カードの薄いglowと装飾アイコンを外してトラックリスト型の一覧にした。
- `anime`: 明るいピンク/空色とCanvasのきらめきは残し、汎用プロフィール絵・飾り記号と作品カードの一律角丸・影・装飾グラデーションを外してマンガ目次型の一覧にした。

次に着手するテーマ（順序付き）: `apple` → `gothic` → `kawaii` → `classy` → `space` → `terminal` → `y2k` → `magazine` → `zen` → `ukiyo-e` → `handheld` → `fantasy-book` → `newspaper` → `data-js` → `winxp` → `brutalist`。
